How it works (RAG)
  1. Ali's CV, projects, skills, education and achievements are split into searchable chunks.
  2. Each chunk is turned into an embedding vector and stored in a vector index.
  3. Your question is embedded and the closest chunks are retrieved (vector + keyword search).
  4. A language model writes the answer using only those chunks, with numbered sources.

If the documents don't contain the answer, it says so instead of guessing.

AI answers can be imperfect — sources are shown under each answer.
